Projects

Spineless Cowboys

An Unreal Engine game currently in development.

The idea for this game is that you can fight other players for bounties, claim the bounties and travel to different planets with space ships. And most importantly, ride horses. I am coding it mainly with blueprint code rather than c++ because it allows for quick prototyping and is inside the editor, unlike coding in c++.

I’ve currently added horse riding, combat with a rifle, animations, full movement system, with a blend space.

Status: In development

Iterate

A factory game I’m making in Python. The project is currently in development.

In this game you can place down different machines, energy sources and relays. You can power machines which will produce materials (which in the future I will add a piping system so you can make materials input to other machines to make more expensive resources).

Status: In development
